# مِشكاة · ملف التسليم (المرحلة الأولى: الواجهة)

منصة إدارة مراكز تحفيظ القرآن الكريم. هاد التسليم فيه **الصفحة الرئيسية فقط** (واجهة أمامية)، بدون أي نظام خلفي، وبدون أي تواصل (لا واتساب ولا نماذج)، وبدون أي ارتباط بـ VELTRIX.

## شو في بالملف

```
mishkat-handoff/
├─ HANDOFF.md            ← هاد الملف
├─ single/index.html     ← الصفحة كاملة بملف واحد (CSS و JS جوّاه)
├─ split/                ← نفس الصفحة مقسّمة، أسهل للدمج بمشروع
│  ├─ index.html
│  ├─ css/mishkat.css
│  ├─ js/config.js       ← الإعدادات (window.MISHKAT)
│  ├─ js/mishkat.js      ← القائمة، الظهور عند التمرير، صورة الخلفية
│  └─ assets/            ← هون بتنحط صورة المسجد والمصحف لما تجهز
└─ screenshots/          ← لقطات كمبيوتر 1536 وتابلت 1100 وموبايل 390
```

النسختين متطابقتين بالشكل. تم فحصهم على 1536 و1100 و390 بكسل: ما في أخطاء بالكونسول ولا تمرير أفقي.

- **بدون أي مكتبات ولا build:** HTML و CSS و JS عادي.
- **الاعتماد الخارجي الوحيد:** خطوط Google (Alexandria للعناوين، Tajawal للنص).
- **الصور:** كل الرسومات (الشعار، الأيقونات، مشهد المسجد المؤقت، الجوالات، اللابتوب) SVG و CSS جوّا الصفحة، فما في ملفات صور لازم تنسخ.

## أقسام الصفحة (بالترتيب)

| القسم | العنصر / id | ملاحظات |
|---|---|---|
| القائمة العلوية | `nav.top` جوّا `#home` | الشعار، البحث، ٦ روابط، «دخول» و«إنشاء حساب». على الموبايل بتصير قائمة منسدلة (`#burger`) |
| الواجهة | `header.hero#home` | العنوان، الوصف، «ابدأ الآن» و«شاهد فيديو تعريفي»، ومشهد المسجد (`svg.scene`) |
| شريط المزايا | `ul.strip` | ٥ مزايا فوق طرف الواجهة |
| الجوالين | `.phones#app` | شاشة الترحيب وشاشة الطالب (عرض فقط، `aria-hidden`) |
| لوحة إدارة المركز | `section#centers` (`.b-dash`) | لابتوب فيه لوحة تحكم تجريبية، أرقام وهمية |
| مميزات المنصة | `section#features` (`.b-feat`) | ٦ بطاقات |
| مخطط النظام | `section#about` (`.b-sys`) | المنصة وتحتها ٤ واجهات |
| الهوية البصرية | `section#identity` (`.b-id`) | الشعار والألوان الأربعة والشعار النصي |
| الباقات | `section#pricing` | ٣ باقات **بدون أسعار** (حلقة، مركز، مؤسسة)، الأسماء والمحتوى مؤقتين |
| التذييل | `footer` | الشعار و«نورٌ في كل بيت» |

اللوحات الأربع (`.board`) بشبكة ١٢ عمود: على الكمبيوتر صفّين (لوحة المركز + المميزات، ثم المخطط + الهوية)، وتحت 1300 بكسل بتنزل تحت بعض.

## الهوية (متغيرات CSS بأول `mishkat.css`)

| المتغير | اللون | الاستخدام |
|---|---|---|
| `--navy` | `#1B2550` | الأساسي (كحلي) |
| `--navy-d` | `#121A3D` | الكحلي الغامق |
| `--gold` | `#E3B062` | الذهبي |
| `--gold-d` | `#C48B38` | الذهبي الغامق |
| `--cream` | `#FFF6E6` | الكريمي |
| `--violet` | `#6F6AA8` | البنفسجي |
| `--goldgrad` | تدرّج | خلفية الأزرار الذهبية |
| `--display` / `--body` | Alexandria / Tajawal | الخطوط |

- **الشعار:** SVG برمز `#logo` (قوس ونجمة وكتاب مفتوح)، بينستخدم بـ `<svg><use href="#logo"/></svg>`.
- **الأيقونات:** ٢٥ أيقونة كرموز `#i-…` بأول `<body>`.
- **المهم بالتقسيم:** رموز الـ SVG لازم تضل جوّا الـ HTML نفسه (مش بملف خارجي)، لأنه `use href="#…"` بيدوّر عليها بنفس الصفحة.

## نقاط المقاسات

- **1300px:** الجوالين بينزلوا تحت الواجهة، واللوحات بتنزل تحت بعض.
- **1020px:** القائمة بتصير منسدلة.
- **860px:** المشهد بينزل تحت النص، والشريط بيصير عمودين.
- **560px:** الموبايل، الجوالين بيصغروا، ولوحة التحكم بتصير عمود واحد.
- **تخفيف الحركة:** `prefers-reduced-motion` بيوقف كل الحركات.

## أشياء مؤقتة لازم تنعرف قبل الدمج

1. **صورة المسجد والمصحف (3D):** لسا ما وصلت. الواجهة فيها مشهد مرسوم مؤقت.
   - **التركيب:** حط الصورة بـ `assets/`، وحط مسارها بـ `heroImage` بملف `config.js` (مثلاً `'assets/mishkat-hero.jpg'`). بتصير الخلفية لحالها والرسم المؤقت بيختفي.
   - **المواصفات:** الأفضل عرض 2000 بكسل أو أكثر، والمسجد والمصحف على اليمين، لأنه النص على اليسار.
   - **تنبيه:** هاد المسار لسا ما تجرّب بصورة حقيقية.
2. **الأزرار كلها بدون وظيفة (`data-soon`):** «إنشاء حساب»، «دخول»، «ابدأ الآن»، «اطلب عرض سعر»، ورابط «تواصل معنا». الضغط عليهم ما بيعمل شي. لما يجهز النظام، شيل `data-soon` وحط الرابط الصح.
3. **زر البحث (`.srch`):** شكل فقط.
4. **«شاهد فيديو تعريفي»:** بينزل على قسم المميزات، لأنه ما في فيديو.
5. **بيانات الجوالين ولوحة التحكم:** كلها وهمية للعرض (أحمد محمد، 120 طالب، 70%، …).
6. **الباقات:** أسماء ومحتوى مؤقتين، ومش مربوطة بأسعار.

## خطوات الدمج المقترحة

1. **اختر النسخة:**
   - إذا مشروعك فيه هيكل ملفات (CSS و JS منفصلين)، خذ `split/`.
   - إذا بدك تحط الصفحة كما هي، خذ `single/index.html`.
2. **تضارب الأسماء:** كل الكلاسات بأسماء قصيرة (`.btn`، `.panel`، `.pill`، `.hero`، …)، وممكن تتضارب مع CSS مشروعك.
   - **الحل الأسهل:** لفّ الصفحة بكلاس واحد (مثلاً `.mishkat`) وسبّق كل القواعد فيه.
   - **أو:** خلّي الصفحة الرئيسية ملف لحالها بدون CSS المشروع العام.
3. **المتغيرات:** إذا عندك متغيرات ألوان بمشروعك، اربطها بمتغيرات `:root` اللي فوق بدل ما تكرر القيم.
4. **إذا الشغل React / Next:**
   - كل قسم من الجدول فوق بيصير component.
   - رموز الـ SVG بتصير component واحد بينحط مرة بأول الصفحة.
   - الـ CSS بيصير module أو global.
   - `mishkat.js` صغير: القائمة، `IntersectionObserver` للظهور، وصورة الخلفية.
5. **الأزرار:** اربطها بصفحات الدخول والتسجيل عندك.
