# VELTRIX · خدمات رقمية

الصفحة الرئيسية: `index.html` (رابط البايو). فيها كل الخدمات مع نماذجها، ونماذج الدعوات، وأسعار الدعوات.

## نماذج الخدمات

| الملف | الخدمة | بتعدّل بياناته من |
|---|---|---|
| menu.html | منيو QR ذكي (`menu.html?t=5` = طاولة ٥) | `window.MENU` بأول الملف |
| booking.html | صفحة حجز مواعيد | `window.BOOK` بأول الملف |
| card.html | بطاقة تعريف رقمية | `window.CARD` بأول الملف |

الصور جوّا الملفات نفسها، فكل ملف شغّال لحاله.

| الملف | التصميم | المناسبة |
|---|---|---|
| premiere.html | العرض الأول (سينمائي) | زفاف |
| rum.html | ليلة الفوانيس (سينمائي) | زفاف |

كل دعوة ملف لحاله. بيانات العرس كلها بأول الملف تحت `window.INVITE`: الأسماء، التاريخ، القاعة، الخريطة، رقم الواتساب، وكود لوحة الردود (`eventId`).

- رابط باسم ضيف: `premiere.html?to=عائلة أبو محمد`
- فتح مباشر بدون الافتتاحية: `premiere.html#open`

## لوحة الردود (باقة VIP)

`lawha.html`: أهل العرس بيشوفوا فيها مين أكد حضوره، وكم شخص، والتهاني، وبينزّلوها Excel. فيها كمان مولّد روابط للضيوف مع إرسال على واتساب.

- النسخة التجريبية للزباين (عرس وهمي مرتب): `lawha.html?e=sample&k=sample`
- لوحة تجاربك من النماذج: `lawha.html?e=demo&k=demo`
- الردود بتنحفظ بـ Supabase (مشروع oz-gym، جداول `inv_*`)، والواتساب بيضل يوصل زي قبل.

### زبون جديد

1. من Supabase ← SQL Editor:
   ```sql
   insert into inv_events (id, title) values ('karim-salma', 'عرس كريم وسلمى') returning secret;
   ```
2. انسخ ملف التصميم باسم جديد (مثلاً `karim-salma.html`)، وعدّل بياناته وحط `eventId: 'karim-salma'`.
3. ابعت لأهل العرس رابط اللوحة: `lawha.html?e=karim-salma&k=المفتاح` (المفتاح هو `secret` اللي طلع بالخطوة ١).
